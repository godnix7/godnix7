01 / About the project

A practical Linux toolkit.

UniMonitor collects system information, CPU and memory use, filesystem state, process summaries, network details, and basic health checks. It can also save a timestamped text report.

02 / Boundaries

The whole menu stays private.

The demo exposes only --help, --version, and --report. Process termination, settings changes, report deletion, user supplied hostnames, and arbitrary commands are unavailable here.
